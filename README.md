# Zynq-7010 FPGA Core Board

一个基于 Xilinx Zynq-7010 的紧凑型 FPGA + ARM 核心板开源项目，IO全引出，核心板只保留基本的外围电路，使用PMIC为核心供电。体积只有40x60mm，八层板设计使用了一阶埋孔，本项目完整开放硬件设计资料，包括原理图、PCB以及生产文件，方便学习和二次开发。

- 使用Cadence17.4设计绘制
- 可以快速查看各个层展示效果[点击此处](PNG/)
- 采用2312叠层阻抗设计请点击[这里](Manufacture/)

本项目仅用于学习、研究和开源交流。实际生产和使用前，请自行确认器件选型、PCB 制造参数及硬件安全性。
