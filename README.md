一个基于 Xilinx Zynq-7010 的紧凑型 FPGA + ARM 核心板开源项目。

本项目完整开源硬件设计资料，包括 原理图、PCB、生产文件及 FPGA 工程，方便学习、二次开发和直接打样。

✨ Features

SoC: Xilinx Zynq-7010

FPGA: Xilinx 7-Series FPGA

ARM: Dual-Core Cortex-A9

PCB: 8 Layers

HDI: 1st-order HDI，盲/埋孔设计

Board Size: 40 × 60 mm

Design: 高密度小型化核心板

Open Source: 原理图 / PCB / Gerber / Drill / FPGA 工程

🛠️ Hardware

核心板采用 Zynq-7010 SoC，配合 DDR、Flash、电源管理及高速接口，实现一个完整的 FPGA + ARM 最小系统。

PCB 采用 8 层板 + 一阶 HDI 盲埋孔设计，在较小尺寸下实现高密度布线。
